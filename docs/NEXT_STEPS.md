## 决定 1：项目怎么定位？

### 选项 A：省砖（"用更少的砖，做出同样稳定的结构"）
- 零件用 1x3 或 2x3：两种都显著省砖，稳定性也没变差。
- 研究问题不变：BrickGPT 需要多少样本（N = 0 / 100 / 500 / 2000）才能学会用新零件？
- 评测：新零件的使用率、用砖数、稳定率不下降。
- 训练：阶段 3 的 LoRA，自然有训练和验证曲线。
- 优点：阶段 2 的代码和数据格式已经写好（`newbrick/build_stage2_data.py`），可以马上开始。
- 缺点：卖点偏弱。

### 选项 B：换一种真正有物理意义的常用零件（推荐考虑 2x2 转角砖）
- 长方形新砖帮不上忙：它们只是把同一个形状换一种切法。
- BrickGPT 的格式和稳定性检查**只支持高度一格的长方形砖**（每块砖只有长、宽、朝向三个参数）。所以真正常用、又可能有用的零件，都需要改代码：

| 零件 | 可能的好处 | 要改什么 |
|---|---|---|
| 2x2 转角砖（L 形，零件号 2357） | 加固墙角，那是两面墙最容易分开的地方 | 稳定性检查要支持 L 形（可以看成 3 个 1x1 格子粘成一块）；文字格式要能表示 L 形的朝向 |
| 薄板（plate，1/3 砖高） | 在一层之内就能错开接缝 | 整个高度单位都要改，工作量最大 |
| 拱砖（arch） | 跨空、做悬挑 | 受力模型要改 |

- 改动量**还没评估**。下一步是花约半天估算转角砖要改多少。
- 优点：卖点更强，有明确的物理理由。缺点：有风险，可能赶不上 proposal。
